# Security Policy

## Versions

When reporting a vulnerability, include the exact LechYTDLP version and whether you installed it from the Microsoft Store or GitHub Releases. If you can safely check the latest version available through that channel, mention whether it is also affected.

## Reporting a vulnerability

Use **Report a vulnerability** on the [Security Advisories page](https://github.com/lechixy/LechYTDLP/security/advisories) if the button is available. Otherwise, open an issue asking [@lechixy](https://github.com/lechixy) for a private security contact. Keep the issue limited to that request.

In your private report, describe the affected versions, the impact, and what you observed. Remove cookies, access tokens, and personal data from any attachments. Keep vulnerability details private while coordinating disclosure with the maintainer.
